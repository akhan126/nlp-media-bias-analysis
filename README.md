# nlp-media-bias-analysis
NLP-based analysis of media bias with a structured data dictionary and codebook documenting features, labels, and text preprocessing decisions.

## Overview
This project applies natural language processing techniques to analyze media bias in news headlines. The work includes text preprocessing, sentiment analysis, and the development of a structured codebook to document features, labels, and analytical decisions for transparency and reproducibility.


## Individual Contribution

This project was completed as a group effort. My primary responsibilities included:

- Performing the initial data cleaning and preprocessing of the text dataset
- Designing and implementing the original sentiment analysis pipeline
- Engineering cleaned and structured text features for sentiment analysis

These contributions supported subsequent analysis and documentation conducted as part of the group project.
